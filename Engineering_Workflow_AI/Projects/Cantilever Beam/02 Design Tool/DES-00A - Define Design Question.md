# Define Design Question

## Illustrative objective

Minimise beam mass while satisfying natural-frequency, static-deflection, strength and manufacturing constraints for a fixed 0.3 m span.

## Design variables

- Material.
- Rectangular width and thickness.
- Optional local reinforcement or taper only after the baseline problem is qualified.

## Required analysis

- First-mode frequency.
- Static tip deflection.
- Root bending stress.
- Sensitivity to dimensions, material properties and boundary compliance.

## Status

This is a skill-test design question. It has not been adopted for a real component and cannot begin until [[Current Approved Analysis Tool]] is populated.
