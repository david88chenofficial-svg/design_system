# Stage Development Cycle

Each stage asks a question, evaluates options and records only the decisions actually made.

```text
stage → decision → reason → evidence/code
                         ↓
                  another decision, if needed
```

The same pattern is repeated for model choice, parameter choice, force calculation, later physics and design iterations. Verification checks that code implements the equations correctly. Validation checks that the model matches physical evidence well enough for its intended use.
