# SIM-00 - Simulation Tool Overview

## Contract

Inputs: seal geometry, operating conditions, model/parameter configuration.

Outputs: increasingly complete predictions of pressure, leakage, forces, non-ideal geometry response, transient behaviour, vibration and FSI.

## Stages

- [[SIM-00A - Define Analysis Question]]
- [[SIM-01 - Model Qualification]]
- [[SIM-02 - Pressure and Leakage]]
- [[SIM-03 - Force and Gap Response]]
- [[SIM-04 - Manufacturing and Wear]]
- [[SIM-05 - Off-Centre and Rotor Tilt]]
- [[SIM-06 - Transient Chamber Dynamics]]
- [[SIM-07 - Vibration and FSI]]
- [[SIM-08 - Simulation Tool Releases]]

The first complete cycle develops and validates pressure/leakage modelling. Every later capability repeats [[Stage Development Cycle]] and must identify the exact upstream release it uses.
