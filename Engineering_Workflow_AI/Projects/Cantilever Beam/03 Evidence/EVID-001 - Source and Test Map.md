# Source and Test Map

## Model sources

1. J. F. Kuzanek, *Finite Element Modeling of a Cantilever Beam*, NASA-TM-X-55743, 1967. Public NASA record: <https://ntrs.nasa.gov/citations/19670013552>. Relevant to uniform-cantilever transverse frequencies with bending, rotary inertia and shear flexibility.
2. MIT OpenCourseWare, *Mechanics and Materials II — Laboratory 1*, 2004. <https://ocw.mit.edu/courses/2-002-mechanics-and-materials-ii-spring-2004/resources/lab_1_s04/>. Contains a cantilever-vibration derivation using classical Euler–Bernoulli theory and discusses refined beam theory.

## Test-method sources

3. ISO 7626-5:2019, *Mechanical vibration and shock — Experimental determination of mechanical mobility — Part 5: Measurements using impact excitation with an exciter which is not attached to the structure*. Official record: <https://www.iso.org/standard/68735.html>.
4. ISO 21289:2008, *Mechanical vibration and shock — Parameters to be specified for the acquisition of vibration data*. Official record: <https://www.iso.org/standard/35831.html>.
