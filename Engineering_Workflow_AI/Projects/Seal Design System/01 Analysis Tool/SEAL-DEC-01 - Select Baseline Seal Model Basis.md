## Decision

TBD. No seal type, performance quantity, operating domain, modelling approach, or acceptance criterion has been selected. A newly proposed model is noted, but its identity, formulation, intended prediction, and applicability are TBD.

If the selected model uses empirical, loss, correction, or carry-over parameters, its parameter definitions and controlled selection basis must also be resolved through [[SEAL-DEC-02 - Select Model Parameter Basis]]. This includes a discharge coefficient and kinetic-energy carry-over term named in the current request; neither value nor formulation is supplied.
